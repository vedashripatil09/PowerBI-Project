# Interactive Sales Dashboard – Power BI

## Project Overview
This project presents an **Interactive Sales Dashboard built using Power BI** to analyze sales performance across regions, categories, subcategories, and time periods.

The dashboard helps identify **sales trends, customer insights, product performance, and regional sales distribution** through interactive visualizations.

---

## Tools & Technologies Used

- Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

---

## Dashboard Features

The dashboard provides multiple analytical views of the sales dataset:

### Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Maximum Sales
- Unique Customers
- Shipping Time

---

### Sales Analysis
- Total Sales by Category
- Sales Amount by Subcategory
- Sales by Country and Region
- Sales Distribution by City
- Monthly Sales Trends

---

### Interactive Filters
Users can dynamically filter the dashboard using:

- Region
- Country
- Month
- Category
- Subcategory

These filters allow deeper analysis of sales patterns.

---

## Visualizations Used

The dashboard includes multiple Power BI visualizations:

- KPI Cards
- Bar Charts
- Pie Charts
- Area Charts
- Tree Diagram
- Map Visualization
- Table View
- Interactive Slicers

---

## Insights Generated

From this dashboard we can analyze:

- Which product categories generate the highest sales
- Regional sales performance
- Monthly sales trends
- Top selling products
- Customer distribution across regions
